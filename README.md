# IPTV Player voor Android TV – releases

Deze repo bevat alleen de **APK-releases** van IPTV Player voor Android TV / Google TV. De broncode is privé.

## Installeren op de TV (eenmalig)
Open in de **Downloader**-app (AFTVnews) op de TV:

```
https://github.com/malik100/Iptv-player-releases/releases/latest/download/IptvPlayer.apk
```

Daarna werkt de app zichzelf bij: hij controleert deze repo op nieuwe versies en vraagt je om te bevestigen.
